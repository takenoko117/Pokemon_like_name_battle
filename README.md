# ネームバトラー (Name Battler) 🎮

入力された文字列（名前）から、ステータス・タイプ・技・グラフィックを自律生成し、ポケモン完全準拠のルールで1vs1のオートバトルを繰り広げるウェブゲームです。

---

## 🌟 ゲームの特徴

1. **名前から生まれるモンスター（ハッシュ生成）**
   - 入力された名前のハッシュ値から、ステータス（HP, A, B, C, D, S）、タイプ、技、ドット絵を決定論的に生成。
   - 同じ名前を入力すれば、常に全く同じモンスターが誕生します。
2. **正規分布による強さのばらつき（合計 60 〜 1200）**
   - 合計値は平均 600 前後が最も出やすく、1000超えの「神個体」や100未満の「最弱個体」が稀に生まれるガチャのようなワクワク感。
3. **ポケモン準拠のバトルシステム**
   - 全18タイプ（単タイプ/複合タイプ対応）。
   - タイプ相性（4倍・2倍・等倍・0.5倍・0.25倍・0倍無効）。
   - タイプ一致補正（STAB 1.5倍）、技命中率判定、急所（1/24で1.5倍）、乱数（0.85〜1.00）。
   - レベル50固定のポケモン公式ダメージ計算式を採用。
4. **スマートなオートAI**
   - 習得した2つの技から、「相手に最も効く技（弱点属性・期待ダメージ最大）」をAIが自律判断して使用。無効技は自動的に回避。
5. **プロシージャル3Dモデル ＆ 2Dドット絵生成（シームレス切り替え対応）**
   - **プロシージャル3Dモンスター**: Three.jsを活用し、名前のシード・タイプ・ステータスから8種類の骨格アーキタイプ（怪獣型、ビースト型、有翼型、マスコット型、ゴーレム型、ドラゴン型、ゴースト型、水棲型）やタイプ特有の装飾パーツ・セルシェーディングマテリアルを動的生成。
   - **生き生きとしたプロシージャルモーション**: 呼吸待機、攻撃突進、被弾のけぞり・シェイク、ひんし倒れ込みアニメーションを実装。
   - **インタラクティブ鑑賞**: マウスやタッチドラッグで360度自由に回転可能。
   - **2D ↔ 3D トグルスイッチ**: ワンクリックで瞬時に「✨ 3Dモデル」「👾 2Dドット」を切り替え可能。さらにステータス開示画面では左右に並べて見比べられる「⚖️ 2D/3D比較（COMPARE）」モードも搭載！
6. **レトロ携帯ゲーム機風の演出**
   - Web Audio APIによるシンセサイザー効果音（打撃、抜群、いまひとつ、急所、瀕死、勝利ファンファーレ）。
   - 速度コントロール（1x / 2x / 4x / SKIP）。

## 🕹 開発・実行方法

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# テスト実行 (Vitest)
npm test

# 本番ビルド
npm run build
```
