# UI & グラフィック仮仕様書

## 1. デザインコンセプト
- **ビジュアルテーマ**: レトロ・携帯ゲーム機風（ポケモン第1〜第3世代 / ゲームボーイアドバンス風）
- **フォント**: ドット・ピクセル調フォント（`'Press Start 2P'`, `'DotGothic16'`, `monospace`）
- **カラーパレット**:
  - メイン背景: 濃紺 / ダークレトロスレート (`#1a1c23`)
  - ウィンドウ枠: 2px〜3px のクラシックな二重線・白黒ベベル
  - HPバー: 高HP（緑 `#2ecc71`）、中HP（黄 `#f1c40f`）、低HP（赤 `#e74c3c`）
  - タイプ別カラー: ポケモン公式イメージカラー（ほのお: 橙、みず: 青、くさ: 緑、でんき: 黄、等）

## 2. プロシージャル・ドット絵生成エンジン（①案）

### 2.1 生成仕様（Canvas 16×16 / 24×24）
名前のハッシュ値から、**左右対称のドット絵モンスター**をCanvas上で動的に生成。

1. **メインカラー・アクセントカラー**:
   - モンスターの第1タイプに基づき、ベース色パレットを決定。
   - 第2タイプまたはハッシュ値からアクセント色を決定。
2. **グリッド構造（左右対称プロシージャル）**:
   - 中心軸（X=12など）に対して左右反転ミラーリング。
   - 体のパーツ（頭部・胴体・手足・角/翼・目）の配置パターンをシード値で決定。
   - 外枠（黒〜濃色のアウトライン）を自動付与してドット絵らしさを強調。
3. **エフェクト**:
   - 待機時は上下に1〜2ピクセル呼吸するように浮遊・バウンスするCSSアニメーション。

## 3. 画面構成とレイアウト

### 3.1 画面1：名前入力・召喚画面
- **入力フォーム**:
  - プレイヤー1の名前入力（例：「サトシ」「ピカチュウ」「りんご」など）
  - プレイヤー2の名前入力（ランダム自動生成ボタン付き）
- **「対戦開始（BATTLE START）」ボタン**

### 3.2 画面2：ステータス開示・VS演出
- 2体の生成モンスター、合計種族値、タイプバッジ、6ステータスのバーグラフ、覚えた2つの技を表示。
- 「合計値が格上！」「タイプ相性はこっちが有利！」といった事前情報が一目でわかる。

### 3.3 画面3：オートバトル画面（対角線配置）
```
+-------------------------------------------------------+
|  [P2: 敵モンスター]                                   |
|   Lv.50 【ゴースト / どく】                             |
|   HP [============       ] 120 / 180                  |
|                   [P2 モンスター ドット絵 (奥)]        |
|                                                       |
|  [P1 モンスター ドット絵 (手前)]                        |
|   [P1: 自分モンスター]                                 |
|   Lv.50 【ほのお】                                     |
|   HP [===================] 240 / 240                  |
+-------------------------------------------------------+
| [ メッセージウィンドウ ]                               |
| 「サトシの かえんほうしゃ！ こうかは ばつぐんだ！」     |
| [ 速度: 1x | 2x | 4x | スキップ ]                      |
+-------------------------------------------------------+
```

### 3.4 バトル演出・アクション
- **こうげき演出**: 前方にスライドして踏み込み。
- **ひっさつ技・被弾演出**:
  - 被弾時に点滅（フラッシュ）＋画面シェイク。
  - HPバーがスムーズに減少。
  - 「きゅうしょに あたった！」「こうかは ばつぐんだ！」の専用メッセージとSE的エフェクト。
- **テンポコントロール**:
  - `1x` (通常テンポ: 約1秒/アクション)
  - `2x` (倍速)
  - `4x` (超倍速)
  - `SKIP` (一瞬で最終ターンまでスキップして勝敗表示)

### 3.5 画面4：リザルト画面
- 勝者モンスターの勝利ポーズ、敗者の消滅演出。
- 決着ターン数、ハイライト（最大与ダメージ技など）。
- 「もう一度たたかう」「別の名前でたたかう」ボタン。

## 4. 3Dモンスター オーラ＆パーティクルシステム（Three.js）

合計種族値（BST: Base Stat Total）のランクに応じて、モンスターの周囲に3Dリアルタイムオーラおよびパーティクルエフェクトが自動展開されます。

### 4.1 通常オーラ（合計種族値 $\le$ 600）
- **ライジングパーティクル（45個）**: 足元からゆっくりと揺らめきながら上昇する属性カラーの光子。
- **足元グラウンドリング**: 淡い回転リングが呼吸に合わせて優しく明滅。

### 4.2 豪華オーラ（600 $<$ 合計種族値 $\le$ 1000：伝説級・600族）
- **多重パーティクルストーム（130個）**:
  - 身体を巡り渦を巻きながら高速上昇するスパイラルパーティクル。
  - 弾ける黄金のスパーク（星型光条粒子）。
- **足元ルーンディスク＆パルス衝撃波**: 足元から波紋のように次々と外側へ拡散・減衰するパルスリング。
- **オーラシリンダー（ピラー）**: 身体を包む半透明加算合成の光の柱が揺らめき脈動。
- **オービタル光輪**: 腰回りを斜めに公転する発光トーラスリング。
- **ダイナミックポイントライト**: モンスター本体と陰影を妖しく照らし出す発光体。

### 4.3 やばいぐらい豪華オーラ（合計種族値 $>$ 1000：神話級・規格外）
- **圧倒的超光子ストリーム（340個）**:
  - DNAのような二重螺旋を描いて天へと舞い上がるダブルヘリックス粒子。
  - モンスター周囲を立体的に高速周回するコズミックダスト（公転粒子）。
  - 四方八方に激しく弾け飛ぶ神聖スパーク＆ライトニング。
  - 時間経過でゴールド・シアン・マゼンタ・白へと移ろうリアルタイムプリズムカラーシフト。
- **神聖二重回転ルーン魔法陣**:
  - 外周ルーンリング（時計回り回転）と内周幾何学リング（反時計回り高速回転）。
  - 3重の強力なパルスウェーブが地面を激しく拡散。
- **天を衝く多層オーラピラー**: 内層（高速逆回転）と外層（脈動プラズマ）の巨大な光柱が天高く突き抜ける。
- **神聖三重ジャイロスコープリング**: X・Y・Z軸それぞれに傾いた3つの光の輪が天球儀のように立体公転。
- **神の後光（Divine Halo）**: 背後に浮かぶ巨大な神聖光輪と8本の放射光芒。
- **強力ダブルダイナミックライト**: 光度3.5の強烈な光源と補助光がモンスター全体を神々しく発光。
- **バトルアクション連動**: 攻撃時（attack）にはオーラピラーが前方に傾斜し、ビーム奔流のように全粒子が前方へ噴出。被弾時（hit）は激しく四散し、ひん死時（faint）は天へ昇華。
