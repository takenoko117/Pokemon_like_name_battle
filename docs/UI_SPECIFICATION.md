# UI & グラフィック仮仕様書

## 1. デザインコンセプト
- **ビジュアルテーマ**: レトロ・携帯ゲーム機風（ポケモン第1〜第3世代 / ゲームボーイアドバンス風）
- **フォント**: ドット・ピクセル調フォント（`'Press Start 2P'`, `'DotGothic16'`, `monospace`）
- **カラーパレット**:
  - メイン背景: 濃紺 / ダークレトロスレート (`#1a1c23`)
  - ウィンドウ枠: 2px〜3px のクラシックな二重線・白黒ベベル
  - HPバー: 高HP（緑 `#2ecc71`）、中HP（黄 `#f1c40f`）、低HP（赤 `#e74c3c`）
  - タイプ別カラー: ポケモン公式イメージカラー（ほのお: 橙、みず: 青、くさ: 緑、でんき: 黄、等）

## 2. プロシージャル・ドット絵生成エンジン（①案）

### 2.1 生成仕様（Canvas 16×16 / 24×24）
名前のハッシュ値から、**左右対称のドット絵モンスター**をCanvas上で動的に生成。

1. **メインカラー・アクセントカラー**:
   - モンスターの第1タイプに基づき、ベース色パレットを決定。
   - 第2タイプまたはハッシュ値からアクセント色を決定。
2. **グリッド構造（左右対称プロシージャル）**:
   - 中心軸（X=12など）に対して左右反転ミラーリング。
   - 体のパーツ（頭部・胴体・手足・角/翼・目）の配置パターンをシード値で決定。
   - 外枠（黒〜濃色のアウトライン）を自動付与してドット絵らしさを強調。
3. **エフェクト**:
   - 待機時は上下に1〜2ピクセル呼吸するように浮遊・バウンスするCSSアニメーション。

## 3. 画面構成とレイアウト

### 3.1 画面1：名前入力・召喚画面
- **入力フォーム**:
  - プレイヤー1の名前入力（例：「サトシ」「ピカチュウ」「りんご」など）
  - プレイヤー2の名前入力（ランダム自動生成ボタン付き）
- **「対戦開始（BATTLE START）」ボタン**

### 3.2 画面2：ステータス開示・VS演出
- 2体の生成モンスター、合計種族値、タイプバッジ、6ステータスのバーグラフ、覚えた2つの技を表示。
- 「合計値が格上！」「タイプ相性はこっちが有利！」といった事前情報が一目でわかる。

### 3.3 画面3：オートバトル画面（対角線配置）
```
+-------------------------------------------------------+
|  [P2: 敵モンスター]                                   |
|   Lv.50 【ゴースト / どく】                             |
|   HP [============       ] 120 / 180                  |
|                   [P2 モンスター ドット絵 (奥)]        |
|                                                       |
|  [P1 モンスター ドット絵 (手前)]                        |
|   [P1: 自分モンスター]                                 |
|   Lv.50 【ほのお】                                     |
|   HP [===================] 240 / 240                  |
+-------------------------------------------------------+
| [ メッセージウィンドウ ]                               |
| 「サトシの かえんほうしゃ！ こうかは ばつぐんだ！」     |
| [ 速度: 1x | 2x | 4x | スキップ ]                      |
+-------------------------------------------------------+
```

### 3.4 バトル演出・アクション
- **こうげき演出**: 前方にスライドして踏み込み。
- **ひっさつ技・被弾演出**:
  - 被弾時に点滅（フラッシュ）＋画面シェイク。
  - HPバーがスムーズに減少。
  - 「きゅうしょに あたった！」「こうかは ばつぐんだ！」の専用メッセージとSE的エフェクト。
- **テンポコントロール**:
  - `1x` (通常テンポ: 約1秒/アクション)
  - `2x` (倍速)
  - `4x` (超倍速)
  - `SKIP` (一瞬で最終ターンまでスキップして勝敗表示)

### 3.5 画面4：リザルト画面
- 勝者モンスターの勝利ポーズ、敗者の消滅演出。
- 決着ターン数、ハイライト（最大与ダメージ技など）。
- 「もう一度たたかう」「別の名前でたたかう」ボタン。
