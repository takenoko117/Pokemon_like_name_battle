# ゲーム基本ロジック仕様書（バトル＆生成エンジン）

## 1. ゲーム概要
- **タイトル（仮）**: Name Battler（ネームバトラー）
- **コンセプト**: 入力された「名前（文字列）」からステータス・タイプ・技を自動生成し、ポケモン準拠のルールで1vs1のオートバトルを行う。
- **プレイ人数**: 1人（プレイヤーが「プレイヤー1の名前」と「プレイヤー2の名前」を入力して観戦）。

---

## 2. 名前からの生成アルゴリズム

### 2.1 ハッシュ化とシード生成
1. 入力された文字列（UTF-8）を `SHA-256` でハッシュ化。
2. ハッシュ値を数値シード（擬似乱数生成器 PRNG、例: XorShift / Mulberry32）に変換。
3. 同一の名前からは常に**完全に同一のモンスター**が生成される（決定論的）。

### 2.2 ステータス生成ロジック
- **対象ステータス（6項目）**:
  - `HP`（ヒットポイント）
  - `A`（こうげき）
  - `B`（ぼうぎょ）
  - `C`（とくこう）
  - `D`（とくぼう）
  - `S`（すばやさ）
- **合計値（BST: Base Stat Total 相当）**:
  - 範囲: **60 〜 1200**
  - 分布: **正規分布（山なり）**
    - 平均 $\mu = 600$
    - 標準偏差 $\sigma \approx 130$（約95%が 340〜860 の間に収まり、1000超えや100未満は数千〜数万分の一の激レア）
- **各値の配分**:
  - シードから6つの正の重み乱数 $w_{HP}, w_A, w_B, w_C, w_D, w_S$ を生成。
  - 各ステータス = $\lfloor \text{合計値} \times \frac{w_i}{\sum w} \rfloor$
  - 各ステータス最低保証: **1以上**（HPのみ最低 **10**）
- **実数値の扱い**:
  - 生成された値を**Lv50での戦闘実数値**として直接使用。

### 2.3 タイプ（属性）生成
- **18タイプ**: ノーマル、ほのお、みず、でんき、くさ、こおり、かくとう、どく、じめん、ひこう、エスパー、むし、いわ、ゴースト、ドラゴン、あく、はがね、フェアリー
- **構成**:
  - 50% の確率で **単タイプ**
  - 50% の確率で **複合タイプ（第1タイプ ＋ 第2タイプ）**

### 2.4 技選定（2種類）
- プリセットされた「技プール」から名前ハッシュにより **2つの異なる技** を選定。
- タイプ一致技（自分の持つタイプと同じ技）が出る確率は高めず、完全ランダム抽選（タイプ不一致で技範囲が広がる、あるいはタイプ一致の超火力になる等の一喜一憂を生む）。

## 4. AI思考ロジック（オート技選択）

毎ターン、AIは以下の式に基づき「相手に最も有効な技」を自動判定して使用。

### 4.1 技の評価値（期待ダメージ計算）
各技について以下を算出：

$$\text{攻撃側ステータス} = \begin{cases} A (\text{攻撃}) & \text{（物理技の場合）} \\ C (\text{特攻}) & \text{（特殊技の場合）} \end{cases}$$
$$\text{防御側ステータス} = \begin{cases} B (\text{防御}) & \text{（物理技の場合）} \\ D (\text{特防}) & \text{（特殊技の場合）} \end{cases}$$

$$\text{相性倍率} = \text{相手タイプ1への倍率} \times \text{相手タイプ2への倍率} \quad (\in \{0, 0.25, 0.5, 1, 2, 4\})$$
$$\text{タイプ一致補正 (STAB)} = \begin{cases} 1.5 & \text{（技タイプが自身のタイプ1または2と一致）} \\ 1.0 & \text{（不一致）} \end{cases}$$

$$\text{期待スコア} = \text{技の威力} \times \text{相性倍率} \times \text{STAB} \times \frac{\text{攻撃側ステータス}}{\text{防御側ステータス}} \times \left(\frac{\text{命中率}}{100}\right)$$

### 4.2 選択ルール
1. 期待スコアが高い方の技を選択。
2. 同値の場合はランダム（50%）。
3. **無効化判定**:
   - 相性倍率が `0倍`（無効）の技はスコア0となり、もう一方の技（倍率 > 0）が必ず選ばれる。
   - 両方の技が `0倍` の場合は、技1を空撃ちする（「こうかがない ようだ…」）。

## 5. バトル進行・ダメージ計算式

### 5.1 ターンの流れ
1. **行動順判定**:
   - `すばやさ(S)` の高い方が先攻。
   - 同速の場合は 50% の確率でランダム決定。
2. **先攻の行動**:
   - AIが技を選択。
   - 命中判定（乱数 $1 \sim 100 \le \text{命中率}$ で命中、失敗で「攻撃ははずれた！」）。
   - ダメージ計算とHP減少処理。
   - 相手のHPが0になったら即時終了（後攻は行動不能）。
3. **後攻の行動**:
   - 生き残っていれば同様に行動。
4. **ターン終了処理**:
   - ターン数をインクリメント。30ターン経過で判定へ。

### 5.2 ダメージ計算式（ポケモン第5世代以降準拠）
全員 Lv50 固定。

$$\text{基本値} = \left\lfloor \frac{\left\lfloor \frac{2 \times 50}{5} + 2 \right\rfloor \times \text{威力} \times \frac{\text{攻}}{\text{防}}}{50} \right\rfloor + 2 = \left\lfloor \frac{22 \times \text{威力} \times \frac{\text{攻}}{\text{防}}}{50} \right\rfloor + 2$$

$$\text{最終ダメージ} = \lfloor \text{基本値} \times \text{STAB} \times \text{相性倍率} \times \text{急所} \times \text{乱数} \rfloor$$

- **急所判定**: $1/24$（約4.17%）の確率で発生、倍率 $1.5$（「きゅうしょに あたった！」）。
- **乱数**: $0.85 \sim 1.00$（16段階または連続乱数）。
- **最低保証**: ダメージが計算上0以下になっても、無効（0倍）以外は最低 **1** ダメージ。

### 5.3 決着判定
- どちらかの HP が 0 になった時点で勝利。
- **最大30ターン** で決着がつかない場合：
  - **残りHP割合（現在HP / 最大HP）** が高いプレイヤーの判定勝ち。
  - 割合も完全同値の場合は「引き分け（DRAW）」。

## 6. データモデル定義（TypeScript例）

```typescript
export type PokemonType =
  | 'normal' | 'fire' | 'water' | 'electric' | 'grass' | 'ice'
  | 'fighting' | 'poison' | 'ground' | 'flying' | 'psychic' | 'bug'
  | 'rock' | 'ghost' | 'dragon' | 'dark' | 'steel' | 'fairy';

export type MoveCategory = 'physical' | 'special';

export interface Move {
  id: string;
  name: string;
  type: PokemonType;
  category: MoveCategory;
  power: number;
  accuracy: number;
}

export interface Stats {
  hp: number;
  attack: number;
  defense: number;
  spAttack: number;
  spDefense: number;
  speed: number;
  total: number;
}

export interface Monster {
  name: string;
  types: [PokemonType] | [PokemonType, PokemonType];
  stats: Stats;
  moves: [Move, Move];
  maxHp: number;
  currentHp: number;
}
```
